# StockSgnal2 1.0.5 — 다음 매수 작성

한 번 접수하면 다음 주문을 작성할 수 없던 제한을 수정했다.

- 주문번호가 확인된 접수 건에는 **새 매수 작성** 버튼이 표시된다. 버튼을 누르고 보관을 확인하면 빈 입력칸으로 돌아간다. 매수 기능을 켠 뒤 새 내용을 입력·확인·본인 인증하면 별도의 주문을 전송한다.
- 보관은 기존 주문의 취소·재전송이 아니다. 이전 미체결 주문은 계속 유지된다. 보관 전에 이를 화면에서 안내한다.
- 이전 주문은 최근 100건까지 암호화 저장하며, **이전 주문 내역**에서 계좌·종목·수량·지정가·주문번호를 확인하고 다시 체결 조회할 수 있다. 접수 기록 자체를 체결 완료로 표시하지 않는다.
- 주문번호가 없거나 접수 여부가 불명확한 대기/통신중단 건은 이 보관 경로로 해제할 수 없다. 이전처럼 증권사에서 확인한 후 처리한다.
- 내역 저장과 현재 주문 해제를 같은 저장 작업으로 처리한다. 저장 실패 시 기존 주문 잠금을 유지한다.
- 기존 1.0.4의 보안 보완과 저장된 현재 주문 기록을 유지한다. 기존 앱을 삭제하지 않고 덮어 설치한다.

25개 단위 테스트와 빌드·필수 Lint 검사 통과. 1.0.4와 같은 설치 서명 사용. 휴대폰의 실제 주문·인증·암호화 기록 저장/조회 동작은 이번 작업에서 실행하지 않았다.
