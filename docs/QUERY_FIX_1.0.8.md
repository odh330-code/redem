# 1.0.8 조회 수정 및 남은 확인

2026-10-03. 실기기 계좌 1의 인증된 응답은 확보되지 않았다. 아래 수정은 조회 성공을 보장하는 실계좌 검증 결과가 아니다.

- 공식 지수 API property 명세에서 일봉 xtick=001 확인. 기존 빈 문자열을 수정했다. 근거 없는 DJUSS 후보와 해당 후보의 기억된 코드 사용을 제거했다. 나무 응답 오류코드를 검사하고 코드별 실패를 보존한다.
- 공식 명세: https://www.nhplug.com/api/apis/guide/tr/property/7599d466-c46b-41f8-b9f2-b0ea74edc2e2
- Yahoo ^DJUSSC의 range=max 및 명시적 period1/period2 응답 모두 일봉 1건만 반환했다. 장기전략 일봉 공급자로 도입하지 않았다. 나무 DJUSSC 지원 여부는 여전히 실제 응답 확인 필요.
- RP는 해외주식 잔고 조회 성공에 종속되어 있었다. 해외주식 잔고 실패 시에도 별도 자산현황을 조회하고 기존 계좌 모델이 있으면 RP 상태를 갱신한다.
- 합산 RP는 한 계좌 실패 시 모든 계좌 금액을 숨기던 것을 수정했다. 조회된 부분 합계와 미조회 상태를 함께 표시한다.
- 외화라고 명시된 RP 상품과 원화 평가 통화가 충돌하면 상품명 기준으로 분류한다. USDRP 및 전각 RP를 처리한다. 이것이 계좌 1의 실원인인지는 아직 확인되지 않았다.
- 임의 Output_2 및 모든 필드 문자열 탐색을 제거했다. 공식 Output_1 파싱과 누락/실패 구분을 적용했다. RP 금액 필드가 없으면 0으로 만들지 않는다.
- 공식 자산현황 명세: https://www.nhplug.com/api/apis/guide/tr/property/40cee985-a2c1-48b8-bbf8-08fdbce9c3ab
- RP 카드에서 조회 내역을 확인할 수 있다. 설정의 지수 진단 카드에도 계좌별 RP 응답 확인 버튼을 추가했다. 계좌번호/키/잔고 금액은 진단 텍스트에 기록하지 않는다. 상품명/상품코드/분류/응답코드/페이지/필드 존재 여부만 기록한다.
- 거래내역 조회는 추가하지 않았다. RP 잔고 API 응답을 확인한 뒤 필요한 추가 수정을 결정한다.
